## v1.0.0 — 首个完整版本

金融知识图谱风险预警与智能投研系统的首个可发布版本。

### 核心能力

**知识图谱**
- 4 类节点（Company / Person / Event / Product）、15 类关系
- 来源溯源是一等值对象：双时间（平台何时知道 / 事实何时成立）+ 抽取置信度 + 证据指纹去重
- 合成数据恒标记为 `sourceType: synthetic`，不会被误认为真实数据
- 5 个版本化 Cypher 迁移（唯一约束 + 范围/文本索引）

**数据接入**
- 多源适配器（CSV / 公开 API / 合成）
- 实体对齐三级级联：统一社会信用代码 → 规范化名称 + 注册地区 → 人工别名表
- 确定性哈希 ID，写入幂等，支持断点续跑

**风险引擎**
- 10 个版本化指标（权重和 = 1，由测试守护）
- YAML 规则引擎，AND 语义
- 乘性衰减传导：每条路径自带瓶颈系数，即分析师的核查起点
- GraphSAGE 用 NumPy 完整实现前向与反向，**不依赖 torch**

**智能投研**
- 意图分类 KGQA，回答附证据路径
- 结构化可比案例检索
- 结构化投研简报生成
- LLM 只润色事实，永不生成 Cypher（消除注入面）

**服务交付**
- FastAPI 分层路由，统一扁平错误信封
- Init / Step / Poll 长任务协议
- Prometheus 指标 + 告警分发（文件 / Webhook）
- 调度器与独立 worker

### 已知边界

- 示例数据为**合成数据**，主体名称均为虚构，不构成任何真实主体的风险判断
- 仓库不宣称任何未实测的准确率；GNN 指标仅在合成数据上验证过
- 真实业务数据需自行接入（工商、公告、裁判文书等公开或授权来源）
- 真实 Neo4j 的并发写入压测未做
