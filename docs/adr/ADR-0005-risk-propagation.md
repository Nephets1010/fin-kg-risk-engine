# ADR-0005：风险传导模型 —— 乘性衰减

- **状态**：已接受
- **日期**：2026-10-29

## 背景

文档目标是「把风险响应时间从 24 小时压缩至 1 小时」。这意味着风险传导必须是**增量**的：不能每次都重算全图。

同时，风控分析师必须能理解「为什么这家没担保的公司也被告警了」。传导模型如果无法解释，预警就会被业务方无视。

## 决策

### 1. 传导强度是**边上的属性**

每种关系类型有一个 `transmissibility`（0~1）：

| 关系 | 传导系数 | 理由 |
|---|---|---|
| `GUARANTEE` 担保 | 1.00 | 债务直接承接，风险几乎完全传导 |
| `CONTROLS` 控制 | 0.95 | 实际控制关系 |
| `HOLD` 持股 | 0.90 | 母子公司财务与信用高度联动 |
| `LEGAL_REP` 法人 | 0.80 | 法人个人风险与主体强相关 |
| `DIRECTOR_OF` 董事 | 0.70 | |
| `INVESTS_IN` 投资 | 0.60 | |
| `RELATED` 关联 | 0.30 | 关联关系过于宽泛，弱传导 |

这个属性是**可解释性的核心**：传导路径上最弱的一环（`TransmissionPath.bottleneck`）正是分析师最该看的地方。

### 2. 分数按**乘性衰减**沿路径传播

```
propagated_score(path) = source_score × Π(transmissibility_i) × decay^(hops-1)
```

`decay` 默认 0.6：每多跳一层，风险打个折扣。乘性模型相比加性模型的好处是**不会因为路径变长而分数变大** —— 一个 5 跳路径的分数必然低于其 1 跳前缀。

### 3. 跳数**硬上限**（默认 3 跳）

超过 3 跳的路径在业务上没有意义（隔着两层担保关系的企业通常已经不在同一风险敞口口径内），且会引入组合爆炸。跳数上限由 `FIN_KG_RISK_MAX_HOPS` 配置。

### 4. 传播是**增量**的

`RiskPropagator._explore` 从源实体出发做有界 BFS，只访问受影响邻域。没有变化的区域不重算。这是「24 小时 → 1 小时」的实现基础：一次事件触发的重算范围是局部而非全图。

### 5. 触发条件：源分 > 0 且传导后分 > 0

源分为 0 时不传播，避免图上大量零分节点产生无意义的路径。

## 被否决的方案

**全图扩散模拟**（在整张图上迭代扩散若干轮）

- 否决原因：计算量随图规模平方增长；输出难以解释；增量更新困难。

**最短路径 + 单一衰减**

- 否决原因：只保留最短路径会丢失「多条路径叠加」的风险信息，也无法体现瓶颈边的位置。

**PageRank 式随机游走**

- 否决原因：输出是相对排名而非绝对风险分，无法与业务阈值对齐；不可解释。

## 后果

**正面**

- 传导路径本身就是证据：告警里直接给出「A -[GUARANTEE]-> B -[GUARANTEE]-> C」。
- 计算量与源实体的度数相关，而非与图规模相关。
- 调参直观：改 `decay` 和 `transmissibility` 即可改变传导的激进程度。

**负面 / 代价**

- 乘性模型假设路径间独立，忽略了多条路径的叠加效应。
- `transmissibility` 的取值是专家经验值，需要持续校准。
- 不区分风险类型：司法风险与市场风险按同一套系数传导。

## 验证方式

- `tests/unit/test_risk.py::TestPropagation`：链路跟随、衰减递减、跳数上限、零分不传播、瓶颈计算、路径可读性。
- 示例数据集 `data/samples/` 构造了一条 3 跳担保链，`fin-kg ask "华信控股集团有限公司的担保链"` 可复现该路径。

## 撤销条件

当业务要求区分风险类型的传导路径，或需要多条路径叠加效应时，引入按风险类型分层的传导系数矩阵，并考虑在局部子图上做扩散模拟。
