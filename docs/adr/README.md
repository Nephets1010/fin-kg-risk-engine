## 写 ADR 的规则

1. **记录决策，不记录过程**。重点是「为什么」和「代价」，不是讨论过程。
2. **必须有撤销条件**。没有撤销条件的决策说明还没想清楚。
3. **必须写出验证方式**。写不出验证方式的决策说明无法落地。
4. **被否决的方案也要写**。避免半年后有人重新提出同一个方案。
5. **状态只有三种**：`提议` / `已接受` / `已废弃`（附替代 ADR 编号）。

## 模板

```markdown
# ADR-XXXX：标题

- **状态**：提议 | 已接受 | 已废弃（见 ADR-YYYY）
- **日期**：YYYY-MM-DD
- **决策者**：角色

## 背景
（决策前的约束与问题）

## 候选方案
（表格对比）

## 决策
（选了什么，关键机制是什么）

## 被否决的方案
（为什么不用另一个）

## 后果
**正面** / **负面 / 代价**

## 验证方式
（怎么证明它真的落地了）

## 撤销条件
（什么情况下重新评估）
```
